# ⛽ FuelCalculator — Calculadora de Combustível

Aplicativo Android nativo desenvolvido em **Kotlin**, com o objetivo de calcular o consumo de combustível e o custo estimado de uma viagem.

Projeto desenvolvido durante meus estudos de desenvolvimento Android na **Nova Era Tech School**.

## 📱 Sobre o aplicativo

O aplicativo permite informar:

- 📍 A distância de uma viagem (km);
- ⛽ O consumo médio do carro (km/L);
- 💰 O preço do combustível por litro (R$).

Com base nesses dados, o aplicativo calcula a quantidade de combustível necessária e o custo total estimado da viagem.

Toda a lógica foi desenvolvida em **Kotlin**, utilizando fundamentos do Android nativo.

## 🧩 Tecnologias e conceitos utilizados

- Kotlin;
- Android Studio;
- Android SDK;
- Activities;
- UI com XML:
  - TextView;
  - EditText;
  - Button;
  - ConstraintLayout;
- Validação de campos;
- Navegação entre telas com Intents;
- Passagem de dados entre telas com Bundle/Intent;
- MaterialToolbar;
- Git e GitHub.
